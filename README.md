# MP-Dashboard para REDMINIMARKET

## Requisitos

- pnpm
- typescript
- node

## Iniciar el proyecto

Instalar dependencias:

```bash
pnpm install
```

Copiar el archivo `.env.example` a `.env` y configurar las variables de entorno:

```bash
cp .env.example .env
```

Inicia el proyecto en modo desarrollo:

```bash
pnpm dev
```

Esto carga el archivo `.env` y ejecuta el proyecto con `node`.
